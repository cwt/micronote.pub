## Defect Description

`inject_config` at [app.py:87-131](../../src/micronote/app.py#L87-L131) is registered with `@app.context_processor`:

```python
@app.context_processor
def inject_config():
    q = {
        "type": "Create",
        "activity.object.type": "Note",
        "activity.object.inReplyTo": None,
        "meta.deleted": False,
    }
    notes_count = DB.activities.count_documents(
        {"box": Box.OUTBOX.value, "$or": [q, {"type": "Announce", "meta.undo": False}]}
    )
    q = {"type": "Create", "activity.object.type": "Note", "meta.deleted": False}
    with_replies_count = DB.activities.count_documents(
        {"box": Box.OUTBOX.value, "$or": [q, {"type": "Announce", "meta.undo": False}]}
    )
    liked_count = DB.activities.count_documents(
        {
            "box": Box.OUTBOX.value,
            "meta.deleted": False,
            "meta.undo": False,
            "type": ActivityType.LIKE.value,
        }
    )
    followers_q = {
        "box": Box.INBOX.value,
        "type": ActivityType.FOLLOW.value,
        "meta.undo": False,
    }
    following_q = {
        "box": Box.OUTBOX.value,
        "type": ActivityType.FOLLOW.value,
        "meta.undo": False,
    }

    return {
        "micronote_version": VERSION,
        "config": config,
        "logged_in": session.get("logged_in", False),
        "followers_count": DB.activities.count_documents(followers_q),
        "following_count": DB.activities.count_documents(following_q),
        "notes_count": notes_count,
        "liked_count": liked_count,
        "with_replies_count": with_replies_count,
        "me": ME,
    }
```

Whenever Flask renders any template via `render_template(...)`, all 5 `count_documents` queries are executed.

### Scope & Invocation Verification

In Flask, context processors are only invoked during template rendering (`render_template`). Non-template routes returning direct `Response` or `flask_jsonify` objects (such as `/robots.txt`, `/nodeinfo`, `/manifest.json`, and `/outbox`) do **not** invoke context processors.

However, all HTML routes—including `/followers`, `/following`, `/liked`, `/note/<id>`, `/search`, login views, and error pages—execute all 5 queries sequentially. With SQLite/NeoSQLite, each count query scans the `activities` collection.

## Impact

- Every HTML page render incurs 5 table queries.
- Header counts are only displayed on a subset of pages; pages that do not render header counts (or error pages) pay this database cost unnecessarily.
- Multi-worker deployments under load experience amplified database lock contention and latency on SQLite.

## Remediation Plan

1. Split `inject_config` into lightweight static config (version, config, me, logged_in) which requires zero database queries.
2. Lazy-load or cache the count metrics with a short TTL (e.g., 30–60s) in `DB.cache2` or an in-memory cache, rather than issuing 5 synchronous queries on every template invocation.
