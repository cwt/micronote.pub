# String Splitting in IndieAuth Scopes Corrupts Authorization Tokens

## Metadata Summary

| Attribute | Value |
| --- | --- |
| **Bug ID** | BUG-001 |
| **Severity** | High |
| **Component** | IndieAuth Endpoints (`indieauth.py`) |
| **Lifecycle Status** | Resolved |
| **Target Files** | [src/micronote/indieauth.py](../../src/micronote/indieauth.py) |

---

## Vulnerability & Defect Description

In `indieauth_flow` ([src/micronote/indieauth.py](../../src/micronote/indieauth.py#L79)), authorization scopes selected by the user are stored into the database as a single space-separated string:

```python
auth = {
    "scope": " ".join(request.form.getlist("scopes")),
    ...
}
```

When the client later redeems the authorization code at `/indieauth` ([line 156](../../src/micronote/indieauth.py#L156)) or `/token` ([line 179](../../src/micronote/indieauth.py#L179)), the endpoints attempt to re-join `auth["scope"]`:

```python
scope = " ".join(auth["scope"])
```

Because `auth["scope"]` is already a `str` (e.g. `"create update"`), calling `" ".join(str)` treats the string as an iterable of single characters.

---

## Impact

- Scopes returned in the JSON payload of token issuance are completely corrupted:
  - `"create"` becomes `"c r e a t e"`.
  - `"create update"` becomes `"c   r   e   a   t   e       u   p   d   a   t   e"`.
- IndieAuth-compliant clients fail scope validation or grant incorrect zero-permission tokens, breaking Micropub and third-party posting integrations.

---

## Root Cause Analysis

The developer presumed `auth["scope"]` was a `list` of strings retrieved from the database, whereas `indieauth_flow` saved it as a serialized string.

---

## Remediation Plan

Ensure `auth["scope"]` is consistently handled as a list or passed directly without re-joining:

```python
scope = auth["scope"] if isinstance(auth["scope"], str) else " ".join(auth["scope"])
```

Or store `auth["scope"]` as a list in `indieauth_flow`:

```python
"scope": request.form.getlist("scopes"),
```

---

## Resolution & Verification

- Implemented `_normalize_scope()` helper in [src/micronote/indieauth.py](../../src/micronote/indieauth.py) to safely accept both strings and collections.
- Updated `indieauth_endpoint` and `token_endpoint` to use `_normalize_scope(auth.get("scope"))`.
- Added unit tests in [tests/test_indieauth.py](../../tests/test_indieauth.py) verifying strings, lists, and empty scopes.
