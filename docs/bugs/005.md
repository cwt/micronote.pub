# Non-Deterministic DOM Element IDs and In-Page Anchors via Python hash()

| Attribute | Value |

| **Severity** | Medium |

---

## Defect Description

In `filters.py` ([src/micronote/filters.py#L133-L136](../../src/micronote/filters.py#L133-L136)):

```python
@blueprint.app_template_filter()
def permalink_id(val):
    return str(hash(val))
```

This filter is used in Jinja templates to generate unique DOM IDs and anchor links:

```jinja2
<div class="note-box" id="activity-{{ obj.id | permalink_id }}">
...
{% set perma_id = obj.id | permalink_id %}
```

In Python 3, `hash()` is salted by a pseudo-random seed (`PYTHONHASHSEED`) generated on process initialization. Because the application runs under Gunicorn with multiple worker processes (or threads), each worker process computes a different integer hash for the identical `obj.id` string.

---

## Impact

- In-page permalinks (`#activity-<id>`) rendered by Worker A break if the client requests the target page or subsequent anchor links handled by Worker B.
- Links bookmarked by users or shared across sessions break whenever the server or worker process restarts.

---

## Root Cause Analysis

Using Python's process-volatile `hash()` built-in for persistent identity formatting instead of a deterministic cryptographic digest.

---

## Remediation Plan

Replace `hash(val)` with a stable, deterministic hash (e.g. SHA-256 or MD5 truncated hex):

```python
import hashlib


@blueprint.app_template_filter()
def permalink_id(val):
    if not val:
        return ""
    return hashlib.sha256(str(val).encode("utf-8")).hexdigest()[:12]
```

---

## Resolution

- Imported `hashlib` in [src/micronote/filters.py](../../src/micronote/filters.py) and refactored `permalink_id` to compute a deterministic SHA-256 hex digest truncated to 12 characters.
- Added empty/None guards returning `""` safely.
- Added comprehensive unit tests in [tests/test_filters.py](../../tests/test_filters.py) to guarantee deterministic output across processes, handling of non-string inputs, empty/None values, and hexadecimal ID format.
