## Defect Description

`admin()` at [admin.py:74-80](../../src/micronote/admin.py#L74-L80) passes `instances=list(DB.instances.find())` to the template:

```python
return render_template(
    "admin.html",
    instances=list(DB.instances.find()),
    ...
)
```

However, [admin.html](../../src/micronote/templates/admin.html) contains no reference to `instances` — the template only uses `inbox_size`, `outbox_size`, `col_followers`, `col_following`, and `col_liked`.

Furthermore, the `DB.instances` collection is never written to anywhere in the codebase (verified by grep). The query always returns an empty list, and the `list()` conversion forces a full cursor iteration on every admin page load for no reason.

## Impact

- Dead DB query on every `/admin` request.
- Template variable `instances` is passed but never consumed — a silent no-op that misleads future maintainers into thinking the admin dashboard tracks external instances.

## Remediation Plan

Remove `instances=list(DB.instances.find())` from the `render_template` call. If the `instances` collection is intended for future use, document it; otherwise drop the reference entirely.
