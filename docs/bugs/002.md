# Unhandled TypeError and HTTP 500 Crash During WebAuthn Login

| Attribute | Value |

---

## Vulnerability & Defect Description

In `admin_login` ([src/micronote/admin.py](../../src/micronote/admin.py#L308-L320)), when WebAuthn credentials exist:

```python
elif credentials:
    assertion = json.loads(request.form.get("assertion"))
    try:
        credential = get_server().authenticate_complete(load_state("login"), credentials, assertion)
    except ValueError as exc:
        current_app.logger.debug(f"webauthn failed: {exc}")
        login_error = "Security key authentication failed."
```

Two failure modes trigger unhandled server exceptions:
1. **Missing or Non-JSON Assertion**: If a user submits the login form without the browser WebAuthn ceremony finishing (e.g. JavaScript blocked, ceremony cancelled, or submitted early), `request.form.get("assertion")` is `None`. `json.loads(None)` raises `TypeError: the JSON object must be str, bytes or bytearray, not NoneType`, which crashes the request with an HTTP 500 error.
2. **Missing Ceremony State**: If the login session state expired, was cleared in another tab, or failed to persist, `load_state("login")` returns `None`. `authenticate_complete(None, ...)` raises unhandled exceptions.

---

## Impact

- Legitimate users encounter raw 500 Internal Server Error pages when logging in if their browser cancels the security key prompt.
- Potential vector for denial of service or log spam.

---

## Root Cause Analysis

- Lack of null-checks and JSON deserialization error handling around `request.form.get("assertion")`.
- Assumption that `load_state("login")` is always present and valid.

---

## Remediation Plan

Validate that the assertion form parameter is present and valid JSON before passing it to `authenticate_complete`, and verify that `load_state("login")` is non-null:

```python
raw_assertion = request.form.get("assertion")
state = load_state("login")
if not raw_assertion or not state:
    login_error = "Security key assertion missing or session expired."
else:
    try:
        assertion = json.loads(raw_assertion)
        credential = get_server().authenticate_complete(state, credentials, assertion)
    except (ValueError, json.JSONDecodeError, Exception) as exc:
        current_app.logger.debug(f"webauthn failed: {exc}")
        login_error = "Security key authentication failed."
```
