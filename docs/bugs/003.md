# Typo in Database Field Name meta.exta in outbox_delete

| Attribute | Value |

---

## Defect Description

In `MicroblogPubBackend.outbox_delete` ([src/micronote/activitypub.py](../../src/micronote/activitypub.py#L428-L431)):

```python
self.DB.activities.update_many(
    {"meta.object.id": obj.id},
    {"$set": {"meta.undo": True, "meta.exta": "object deleted"}},
)
```

Notice the typo `"meta.exta"` instead of `"meta.extra"`. 

By contrast, the corresponding method `inbox_delete` ([src/micronote/activitypub.py#L403-L406](../../src/micronote/activitypub.py#L403-L406)) sets:

```python
self.DB.activities.update_many(
    {"meta.object.id": obj.id},
    {"$set": {"meta.undo": True, "meta.extra": "object deleted"}},
)
```

---

## Impact

- Queries or audit logs inspecting `meta.extra` will fail to find the deletion reason for outbox activities.
- Introduces schema drift across MongoDB/NeoSQLite document records.

---

## Root Cause Analysis

A simple typographical error (`meta.exta` missing the letter `r`) when porting delete cascades.

---

## Remediation Plan

Correct the field name in [src/micronote/activitypub.py](../../src/micronote/activitypub.py#L430):

```python
self.DB.activities.update_many(
    {"meta.object.id": obj.id},
    {"$set": {"meta.undo": True, "meta.extra": "object deleted"}},
)
```

---

## Resolution & Verification

- Corrected `"meta.exta"` to `"meta.extra"` in `MicroblogPubBackend.outbox_delete` in [src/micronote/activitypub.py](../../src/micronote/activitypub.py).
- Created unit tests in [tests/test_activitypub_delete.py](../../tests/test_activitypub_delete.py) confirming that `outbox_delete` writes the correct `meta.extra` field.
