## Defect Description

In `cache_actor_icon` ([src/micronote/utils/media.py#L175-L183](../../src/micronote/utils/media.py#L175-L183)):

```python
def cache_actor_icon(self, url: str) -> None:
    if self.get_file(url, 50, Kind.ACTOR_ICON):
        return
    i = load(url, self.user_agent)
    for size in [50, 80]:
        t1 = i.copy()
        t1.thumbnail((size, size))
        self._store(_encode_image(t1), url, size, WEBP_MIMETYPE, Kind.ACTOR_ICON)
```

In `worker.py` ([src/micronote/worker.py#L250-L254](../../src/micronote/worker.py#L250-L254)):

```python
icon = actor.icon
icon_url = icon.get("url") if isinstance(icon, dict) else None
if icon_url:
    MEDIA_CACHE.cache(icon_url, Kind.ACTOR_ICON)
```

Unlike `cache_attachment` (which catches `ValueError` and `OSError` and falls back gracefully), `cache_actor_icon` does not wrap `load()` in a `try...except` block, and `worker.py` does not catch exceptions from `MEDIA_CACHE.cache(icon_url, Kind.ACTOR_ICON)`.

If a remote actor has an invalid image URL, unsupported image encoding, non-image content type, or an image exceeding the size limit, `load()` raises `ValueError`, `OSError`, or `requests.HTTPError`.

---

## Impact

- The `cache_attachments` job fails completely and is retried 9 times with exponential backoff before being abandoned as `STATUS_FAILED`.
- Any subsequent processing in that job (such as caching note attachments) is aborted.

---

## Root Cause Analysis

Lack of defensive exception handling for untrusted third-party media in `cache_actor_icon` and `worker.py`.

---

## Remediation Plan

Wrap avatar loading in `cache_actor_icon` with a `try...except` block, and handle exceptions in `worker.py`:

```python
def cache_actor_icon(self, url: str) -> None:
    if self.get_file(url, 50, Kind.ACTOR_ICON):
        return
    try:
        i = load(url, self.user_agent)
    except Exception:
        # Non-decodable or unreachable icon: skip caching safely
        return
    for size in [50, 80]:
        t1 = i.copy()
        t1.thumbnail((size, size))
        self._store(_encode_image(t1), url, size, WEBP_MIMETYPE, Kind.ACTOR_ICON)
```

---

## Resolution

- In [src/micronote/utils/media.py](../../src/micronote/utils/media.py), wrapped `load(url, self.user_agent)` in `cache_actor_icon` with a `try...except Exception` block to skip caching gracefully on unreachable or un-decodable remote images.
- In [src/micronote/worker.py](../../src/micronote/worker.py), wrapped `MEDIA_CACHE.cache(icon_url, Kind.ACTOR_ICON)` in a `try...except Exception` block with structured logging so failure to cache an avatar does not abort the task or trigger repeated retry backoffs.
- Added comprehensive unit tests in [tests/test_media_worker.py](../../tests/test_media_worker.py) verifying graceful error handling for corrupted image streams, network connection errors, and cached avatar skips.
