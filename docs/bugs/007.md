## Defect Description

In `build_ordered_collection` ([src/micronote/activitypub.py#L676-L711](../../src/micronote/activitypub.py#L676-L711)):

```python
def build_ordered_collection(col, q=None, cursor=None, map_func=None, limit=50, col_name=None, first_page=False):
    col_name = col_name or col.name
    collection_id = f"{BASE_URL}/{col_name}"
    if q is None:
        q = {}

    if cursor:
        try:
            q["_id"] = {"$lt": ObjectId(cursor)}
        except Exception:
            abort(400)
    data = list(col.find(q, limit=limit).sort("_id", -1))
    ...
    total_items = col.count_documents(q)
```

Two bugs occur during collection pagination:
1. **In-Place Dictionary Mutation**: `q` is not copied with `q = q.copy()`. Any caller passing a shared dictionary has its dictionary mutated with cursor boundaries.
2. **Corrupted `totalItems` Count on Paged Views**: Because `q` was mutated to include `{"$lt": ObjectId(cursor)}`, the `total_items = col.count_documents(q)` call calculates only the count of documents *after the cursor* instead of the total number of items in the collection.

---

## Impact

- External Fediverse servers paginating collections (such as `/outbox`, `/inbox`, `/followers`, `/following`, or `/liked`) receive unstable and shrinking `totalItems` counts on subsequent pages.
- Callers reusing query dictionaries experience unintended side effects.

---

## Root Cause Analysis

- Failure to shallow-copy `q` before adding cursor filter constraints.
- Running `col.count_documents(q)` after applying the cursor filter rather than before.

---

## Remediation Plan

Copy `q` and compute the total count on the base query before applying the cursor constraint:

```python
base_q = q.copy() if q is not None else {}
total_items = col.count_documents(base_q)

query_with_cursor = base_q.copy()
if cursor:
    try:
        query_with_cursor["_id"] = {"$lt": ObjectId(cursor)}
    except Exception:
        abort(400)

data = list(col.find(query_with_cursor, limit=limit).sort("_id", -1))
```

---

## Resolution

- In [src/micronote/activitypub.py](../../src/micronote/activitypub.py), modified `build_ordered_collection` to shallow copy the input query dictionary `q` into `base_q`.
- Computed `total_items = col.count_documents(base_q)` on the base query before any pagination constraints are introduced.
- Created `query_with_cursor` to apply `{"$lt": ObjectId(cursor)}` isolation, ensuring caller query dictionaries are not mutated and pagination pages report the consistent collection `totalItems` count.
- Added comprehensive unit tests in [tests/test_collections.py](../../tests/test_collections.py) verifying query dictionary immutability, `totalItems` preservation across cursor-paginated requests, and abort behavior on invalid cursors.
